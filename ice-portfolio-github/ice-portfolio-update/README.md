# Ice Pongphisut portfolio

Next.js 15, Tailwind v4, Motion, Phosphor icons, Geist + IBM Plex Sans Thai.

    npm install
    npm run dev      # http://localhost:3000
    npm run build    # static export to /out (deploy to Vercel, Netlify or any static host)

All content is in `lib/work.ts`:
- Short form / motion items accept an optional `videoUrl` once your clips are hosted.
- `stills` uses Picsum placeholders. Replace with your real banners and keep the w/h values.
